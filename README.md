This project was fully created by me from scratch using Roblox Studio.

A Roblox survival horror game where players explore the dense, haunted forests of Kaliurang, Indonesia, and attempt to survive a lurking, legendary creature.

🚀 How to Play You can try the game using either method below:

1️⃣ Download the .rblx File from GitHub

Go to the Releases tab or open the folder where the .rblx file is stored.
Click the .rblx file.
Download the file.
Open Roblox Studio.
Select File → Open…
Locate and open the downloaded .rblx file.
Press Play to test the game directly in Roblox Studio.
2️⃣ Play Directly on Roblox

If you prefer to play without downloading, visit the my Roblox page: https://www.roblox.com/share?code=05232bf9edd088428f676d08f87a1e57&type=ExperienceDetails&stamp=1765037505889
